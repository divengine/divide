divide 0.4.0 has an MCP server of its own: an AI coding agent can check, render and trace the templates of the project open in divide, through the real Div engine and with the project's Div setup, the way divide does it.

## The MCP server

- **Options > MCP server** starts it on `http://127.0.0.1:8765/mcp`, stops it, restarts it, and changes its host and port. The dialog shows whether it runs, its address, the project, the requests and the clients, and why it could not start (a port another program listens on, for example). **Copy client setup** puts the configuration for an MCP client on the clipboard.
- Seven tools: `project_info` (PHP, the Div engine, the Div setup in effect and Div's verdict on it), `div_check` (the editor's checks of a template), `div_render` (a render as Ctrl+F9 does it), `div_trace` with `div_trace_page` and `div_trace_mutation` (the render trace, paged), and `div_check_dialect`. They take the saved files or text you pass, unsaved.
- It never starts unless you ask (or check **Start with divide**). It follows the project when another folder opens, and stops with divide.
- Both generations of the protocol: 2026-07-28 and 2024-11-05 to 2025-11-25 (`initialize`), which most clients speak today. No sessions: a restarted server keeps its clients.
- `divide --mcp PROJECT` serves the same tools over stdio, without the interface, for clients that start their servers as processes.
- Nothing to install: it is part of divide, in the binaries too.

Safe by default: only this machine can connect (`127.0.0.1`; the `Host` and `Origin` headers are checked, so web pages cannot reach it); a token is required on a network address, and can be required on `127.0.0.1` too. Paths stay inside the project, nothing is written, outputs and run time are bounded, and closing the connection stops a call and its PHP. A render runs the project's PHP: start the server only on projects you trust. The trust you gave, or did not give, to a project's `php` settings in Options > Div setup is kept; the server never grants it.

See [MCP Server](https://github.com/divengine/divide/wiki/MCP-Server) in the help.

## Also

- divide describes itself as an IDE for developing generators with the Divengine ecosystem: the Welcome window, the About box, `divide --help` and the README.
- Closing a window, a folder or divide while work is still under way (a render's answer, a tree reload, a repaint, the Dialector's or the Div setup's verdict) no longer brings divide down.

## Install

Ready to run, with nothing else to install:

- macOS and Linux: `brew install divengine/tap/divide`
- Windows: `scoop install https://github.com/divengine/divide/releases/latest/download/divide.json`, or the `.msi` below
- Linux: the `.deb`, `.rpm`, `.apk` and Arch packages, the AppImage or the binary alone, below
- macOS: the archive for Apple silicon or Intel, below

Rendering and checking includes need PHP 8 and Div (`composer require divengine/div`); the Git menu needs git. divide is free software under the GPL, version 3 or later. The binaries are not signed yet: see [Installation](https://github.com/divengine/divide/wiki/Installation).
