The first release of divide: the Div template IDE that lives in your terminal, in the spirit of the Borland IDEs.

## What it brings

- **Speaks Div**: every construct highlighted, in the template's own dialect.
- **Errors before you render**: unclosed loops and conditions, orphan closings, broken JSON, includes Div cannot resolve, in the editor and in the Messages window.
- **Completion from your data**: the keys of the template's JSON, the fields of a loop's item, your templates, every Div construct as a snippet.
- **The real engine**: Ctrl+F9 renders through PHP and Div, unsaved edits included; the render trace (F7) replays how Div turned the template into its output.
- **Data as code or as a tree**, the **Dialector** to build and translate dialects, and **Div setup** as your application sets it up.
- **PHP next to the templates**: highlighting, `php -l` as you type, language servers (phpactor, intelephense), run and debug with Xdebug, a web server with `php -S`, Composer packages.
- **Outline** of templates, PHP and the rest, and a **project window** that creates, renames, moves and deletes files and folders.
- **English and Spanish**, four colour themes, and it works in any terminal: over SSH, in tmux, on the server.

## Install

Ready to run, with nothing else to install:

- Windows: `scoop install https://github.com/divengine/divide/releases/latest/download/divide.json`, or the `.msi` below
- macOS: the archive for Apple silicon or Intel, below
- Linux: the `.deb`, `.rpm`, `.apk` and Arch packages, the AppImage or the binary alone, below

Rendering and checking includes need PHP 8 and Div (`composer require divengine/div`). divide is free software under the GPL, version 3 or later. The binaries are not signed yet: see [Installation](https://github.com/divengine/divide/wiki/Installation).
