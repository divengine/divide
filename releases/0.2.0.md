divide 0.2.0 brings git into the IDE: what changed, the diffs, commits, the history, branches, merges and the pull requests, without leaving the editor.

## Git

- **What changed, at a glance**: the project window puts git's letter after each changed file (`M`, `A`, `?`, `U`...) and `•` after the folders that hold changes, and dims what `.gitignore` leaves out; the editor's margin marks the lines added, changed or removed since the last commit, as you type.
- **Git > Changes**: the files in their areas (staged, changes, untracked, conflicts). Space stages or unstages, Del discards, Ctrl+K commits (amend, stage everything first).
- **Diffs as a code review shows them**: the code on red and green, the words that changed brighter, the old and new line numbers, in the editor's colours (Div in its dialect, PHP, HTML, CSS, JSON...). Unified or side by side (S); N and P go from change to change; Enter opens the file at that line.
- **Git > History**: every branch as a graph, each commit's details and diff; the history of one file.
- **Git > Branches**: switch, create, delete, merge into the current branch; the stashes, to bring back or apply. A merge's conflicts show git's markers, our side and theirs; Space marks a file solved.
- **Blame**: each line with the commit, date and author that last changed it; Enter opens that commit.
- **Pull, push and fetch**, with git's words in a progress box.
- **Pull requests and issues** of GitHub (through `gh`) and Gitea, Forgejo or Codeberg (through `tea`): the open ones, a new pull request from the current branch, a new issue, checkout and merge.

It uses the `git` installed on the system, with your settings and credentials. See [Git](https://github.com/divengine/divide/wiki/Git) in the help.

## Also

- Commit subjects and other labels that look like markup (`[/$products]`) no longer break the trees.
- The project window keeps its bar where it should after a paste or a reload on slow machines.

## Install

Ready to run, with nothing else to install:

- macOS and Linux: `brew install divengine/tap/divide`
- Windows: `scoop install https://github.com/divengine/divide/releases/latest/download/divide.json`, or the `.msi` below
- Linux: the `.deb`, `.rpm`, `.apk` and Arch packages, the AppImage or the binary alone, below
- macOS: the archive for Apple silicon or Intel, below

Rendering and checking includes need PHP 8 and Div (`composer require divengine/div`); the Git menu needs git. divide is free software under the GPL, version 3 or later. The binaries are not signed yet: see [Installation](https://github.com/divengine/divide/wiki/Installation).
