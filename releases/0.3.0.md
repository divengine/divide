divide 0.3.0 starts the way VS Code does: it opens a folder only when you give it one, and with nothing it shows a Welcome window with your recent folders and files.

## A folder, a file, or nothing

- `divide .` or `divide ~/sites/shop` opens that folder as the project. `divide page.tpl` opens the file on its own, with no folder. `divide` alone no longer makes the folder you happen to be in the project.
- **The Welcome window**: a new file, open a file, open a folder, the help, and the folders and files you opened lately, newest first. Enter opens one, Del takes it off its list, typing filters. **Help > Welcome** shows it again.
- **File > Open folder** makes another folder the project. The last folder's windows close, after asking about unsaved changes, and its language servers, debugger and web server stop. **File > Close folder** goes back to the Welcome window.
- With no folder, Ctrl+B, Find in files and the project's Div setup offer to open one.

See [The Desktop](https://github.com/divengine/divide/wiki/The-Desktop#a-folder-a-file-or-nothing) in the help.

## Also

- **The mouse wheel works in the dialogs' lists**: File > Open's files, the command palette, the messages, the input histories, the Div setup and Dialector sections, Composer's search. Each notch moves the bar three rows.

## Install

Ready to run, with nothing else to install:

- macOS and Linux: `brew install divengine/tap/divide`
- Windows: `scoop install https://github.com/divengine/divide/releases/latest/download/divide.json`, or the `.msi` below
- Linux: the `.deb`, `.rpm`, `.apk` and Arch packages, the AppImage or the binary alone, below
- macOS: the archive for Apple silicon or Intel, below

Rendering and checking includes need PHP 8 and Div (`composer require divengine/div`); the Git menu needs git. divide is free software under the GPL, version 3 or later. The binaries are not signed yet: see [Installation](https://github.com/divengine/divide/wiki/Installation).
