# 2.9 Fórmulas

Las fórmulas evalúan expresiones PHP dentro de las plantillas. Solo se permite un conjunto restringido de funciones de PHP. Consulta [[05.01 Apéndice A - Funciones PHP permitidas|05.01 Appendix A - Allowed PHP functions]].

**Sintaxis**

```html
(# formula #)
(# formula : number format #)
```

El formato de números sigue las reglas de [[02.08 Formatos de datos|02.08 Data formats]].

**Ejemplo**

index.tpl

```html
{= number: 200.000 =}
{= price: 20.000 =}
{= tax: 0.345 =}

5 + {$number} = (# 5 + {$number} #)

Price with tax: $ {$price} + $ {#tax:2.#} = $ (# {$price} + {$tax} :2. #)
```

Salida

```html
5 + 200 = 205

Price with tax: $20 + $0.35 = $20.35
```
