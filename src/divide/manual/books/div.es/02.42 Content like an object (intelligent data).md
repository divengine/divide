# 2.42 Contenido como un objeto (datos inteligentes)

Los valores que se pasan al constructor de div pueden ser objetos, arrays o una mezcla de ambos. Las plantillas pueden acceder a las propiedades y los métodos de los objetos según el ámbito actual.

Nota interna: Div combina los datos de los ámbitos con una función auxiliar de copia profunda (históricamente llamada `cop`) de `divengine/functions`. Es un comportamiento interno y no forma parte de la API pública.

## 6.42.1 Ejemplo en el ámbito de la plantilla

index.php

```php
<?php

include 'div.php';

class MyData{
    public $values;

    public function __construct($values){
        $this->values = $values;
    }

    public function implode(){
        return implode(",", $this->values);
    }
}

echo new div('index.tpl', new MyData(["A","B","C","D"]));
```

index.tpl

```div
{= data: ->implode() =}

{$data}
```

Salida

```text
A,B,C,D
```

## 6.42.2 Ejemplo en el ámbito de una cápsula

index.php

```php
<?php

include 'div.php';

class MyString{
    public $value;

    public function __construct($value){
        $this->value = $value;
    }

    public function upper(){
        return strtoupper($this->value);
    }
}

echo new div('index.tpl', ['name' => new MyString('peter')]);
```

index.tpl

```div
[[name
    {$value}

    {= up: ->upper() =}

    {$up}
name]]
```

Salida

```text
peter
PETER
```

## 6.42.3 Acceso directo a métodos (desde la 4.7)

index.tpl

```div
{= up: ->name.upper() =}
{$up}
```

Salida

```text
PETER
```

## 6.42.4 Ejemplo en el ámbito del cuerpo de un bucle

index.php

```php
class Person{
    public $first_name;
    public $last_name;

    public function __construct($first_name, $last_name){
        $this->first_name = $first_name;
        $this->last_name = $last_name;
    }

    public function getName(){
        return $this->first_name.' '.$this->last_name;
    }
}

echo new div('index.tpl', [
    'people' => [
        new Person('John', 'Nash'),
        new Person('Albert', 'Einstein'),
        new Person('Jacque', 'Fresco')
    ]
]);
```

index.tpl

```div
[$people]
    {= complete_name: ->getName() =}

    First name: {$first_name}
    Last name: {$last_name}
    Complete name: {$complete_name}

[/$people]
```

Salida

```text
First name: John
Last name: Nash
Complete name: John Nash

First name: Albert
Last name: Einstein
Complete name: Albert Einstein

First name: Jacque
Last name: Fresco
Complete name: Jacque Fresco
```
