# 2.16 Reemplazo por defecto para una variable

Los reemplazos por defecto pueden limitarse a una variable concreta.

## 6.16.1 Uso en PHP

```php
<?php

div::setDefaultByVar($varname, $value_to_search, $replace_with, $update);
```

## 6.16.2 Uso en la plantilla

```
{@ ['varname', value_to_search, replace_with] @}
```
