# 2.20 Etiquetas amigables

Algunos IDE consideran la sintaxis de Div como HTML no válido. Las etiquetas amigables permiten envolver el código Div en comentarios HTML para evitar falsos positivos en los editores.

**Sintaxis**

```
<!--| ... some Div code here ... |-->
```

**Ejemplo**

```
This:

<!--| [$products] |-->
    Name: {$name}
    Price: {$price}
<!--| [/$products] |-->

Is equal to:

[$products]
    Name: {$name}
    Price: {$price}
[/$products]
```
