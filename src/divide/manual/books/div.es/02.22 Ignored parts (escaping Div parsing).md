# 2.22 Partes ignoradas (escapar del análisis de Div)

Los bloques ignorados pasan sin cambios. El analizador no interpreta las etiquetas que hay dentro de estos bloques.

**Sintaxis**

```
{ignore}
    ... some ignored code here ...
{/ignore}
```

**Ejemplo**

index.php

```php
echo new div('index.tpl', ['name' => "Peter"]);
```

index.tpl

```
{ignore}

Name: {$name}

{/ignore}
```

Salida

```
Name: {$name}
```
