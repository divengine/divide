# 2.21 Comentarios

Los comentarios se eliminan de la salida y no se envían al navegador.

**Sintaxis**

```
<!--{ inline comment here }-->

<!--{
    Multi-line comment here
    This multiline comment is not sent to browser.
}-->
```

**Ejemplo**

```
<h1>Hello world</h1>

<!--{ This is a comment }-->
<span>Powered by Div</span>
```

**Salida**

```
<h1>Hello world</h1>
<span>Powered by Div</span>
```
