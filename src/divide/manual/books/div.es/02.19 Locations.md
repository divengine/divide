# 2.19 Ubicaciones

Las ubicaciones definen puntos de inserción con nombre en una plantilla, lo que permite componer contenido desde distintas secciones de la plantilla.

**Sintaxis**

Definir una ubicación:

```
(( location_name ))
```

Definir el contenido de una ubicación:

```
{{location_name

... some content here ...

location_name}}
```

**Ejemplo**

layout.tpl

```
<html>
    <body>
        <div id="header">(( header ))</div>
        <div id="content">(( content ))</div>
        <div id="footer">(( footer ))</div>
    </body>
</html>
```

index.tpl

```
{% layout %}

{{header
    This is the header
header}}

{{footer
    This is the footer
footer}}

{{content
    This is the content
content}}

{{header
    <br/>.... more in the header .....
header}}
```

Salida

```
<html>
    <body>
        <div id="header">This is the header<br/>.... more in the header .....</div>
        <div id="content">This is the content</div>
        <div id="footer">This is the footer</div>
    </body>
</html>
```

## 6.19.1 Limpiar las etiquetas de ubicación

Por defecto, Div elimina las etiquetas de ubicación después del análisis. Puedes controlarlo durante los ciclos de análisis con la variable de configuración `div.clear_locations`.

Ejemplo

```
{= div.clear_locations: false =}
```

Esto conserva las etiquetas de ubicación mientras se componen plantillas preprocesadas; las etiquetas de ubicación que queden se limpian al final del análisis de nivel superior.
