# 2.27 Macros

Las macros ejecutan PHP restringido dentro de las plantillas. Están pensadas para transformaciones pequeñas y controladas y no deben sustituir a la lógica de la aplicación.

**Sintaxis**

```
<?
// ... PHP code ...
?>
```

**Ejemplo**

index.php

```php
<?php

include 'div.php';

class Page extends div{
    public function upper($str){
        return strtoupper($str);
    }
}

echo new Page('index.tpl', [
    'products' => ['Banana', 'Potato']
]);
```

index.tpl

```
{= text: "hello" =}

{$text}

<?
    // upper() is a method of current class
    $text = upper($text);
?>

{$text}

Products:

<?
    $i = 0;
    foreach ($products as $product) {
        $i++;
        echo "$i - $product\n";
    }
?>

There are {$i} products
```

Salida

```
hello

HELLO

Products:

1 - Banana
2 - Potato

There are 2 products
```

## 6.27.1 Restricciones

- `$this` y `self` no están permitidos.
- Por defecto solo se permite un conjunto restringido de funciones de PHP. Puedes ampliar esta lista con `setAllowedFunction`.
- No se permite definir funciones ni clases.
- No se permite incluir otros scripts.

## 6.27.2 Posibilidades

- Crear variables de la plantilla.
- Modificar variables de la plantilla.
- Imprimir salida con echo (evita crear bucles infinitos).
- Usar como funciones los métodos auxiliares de div permitidos.
- Si la clase actual extiende div, puedes llamar directamente a sus métodos.
