# 4.2 Recursión

Div interpreta una plantilla una y otra vez hasta que no es posible hacer más reemplazos. Es un proceso de convergencia, no un algoritmo recursivo, y no usa la pila de llamadas.

Ejemplo

index.php

```php
<?php

include 'div.php';

$product = new stdClass();
$product->name = 'Banana';
$product->price = 20.5;

echo new div('index.tpl', [
    'product' => $product,
    'object' => 'product'
]);
```

index.tpl (origen)

```
[${$object}]

{$_key} = {$value}

[/${$object}]
```

Paso 1

```
[$product]

{$_key} = {$value}

[/$product]
```

Paso 2

```
[$product]

name = {$value}

[/$product]
```

Paso 3

```
[$product]

name = Banana
price = {$value}

[/$product]
```

Paso 4

```
name = Banana
price = 20.5
```
