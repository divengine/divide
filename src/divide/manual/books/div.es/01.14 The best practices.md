# 1.14 Buenas prácticas

## 5.1 Mantén la lógica de negocio fuera de las plantillas

Las plantillas no deberían calcular totales del dominio ni inferir datos que faltan. Por ejemplo, los totales de una factura deberían calcularse en PHP y pasarse a la plantilla. El lenguaje de plantillas está pensado para la presentación, no para derivar reglas de negocio.

## 5.2 Equilibra las responsabilidades de la plantilla y los datos

Evita pasar un exceso de datos que la plantilla nunca usará, y evita poner en las plantillas un exceso de lógica que el motor descartará. Mantén el modelo de datos y la plantilla en equilibrio para que cada uno haga solo aquello para lo que está diseñado.

## 5.3 Prefiere plantillas pequeñas y reutilizables

Divide las plantillas en componentes enfocados que sirvan a un único propósito. No pongas diseños no relacionados en un mismo archivo con grandes bloques condicionales. Si se necesitan varios diseños, usa includes o plantillas preprocesadas para componerlos de forma intencionada.
