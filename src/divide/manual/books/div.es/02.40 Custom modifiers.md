# 2.40 Modificadores personalizados

Los modificadores personalizados amplían el sistema de modificadores de variables. Un modificador personalizado puede ser una función o un método estático, y debe aceptar un único parámetro.

**Ejemplo**

index.php

```php
<?php

include 'div.php';

class MyModifiers {
    public static function upper($value){
        return strtoupper($value);
    }
}

function lower($value){
    return strtolower($value);
}

div::addCustomModifier('upper:', 'MyModifiers::upper');
div::addCustomModifier('lower:', 'lower');

echo new div('index.tpl', ['text' => 'Hello World']);
```

index.tpl

```
{upper:text}

{lower:text}
```

Salida

```
HELLO WORLD

hello world
```
