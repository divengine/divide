# 4.1 Componentes

Los componentes son fragmentos de plantilla reutilizables que encapsulan lógica de presentación y se pueden componer en vistas más grandes.

## 8.1.1 Construir un componente

combobox.tpl

```
<select id="{$id}" name="{$name}">
    [${$options}]
        <option value="{$val}">{$text}</option>
    [/${$options}]
</select>
```

Este componente usa [[02.03 Reemplazos simples|02.03 Simple replacements]], [[02.10 Listas (bucles)|02.10 Lists (loops)]] y [[04.02 Recursión|04.02 Recursion]].

## 8.1.2 Usar un componente

index.tpl

```
[[_empty
    {= id: "products" =}
    {= name: "products" =}
    {= options: "products" =}
    {% combobox %}
_empty]]
```

Usar un componente equivale a incluir un fragmento de plantilla, a menudo dentro de una cápsula.

## 8.1.3 Proporcionar los datos

index.php

```php
<?php

echo new div('index.tpl', [
    'products' => [
        ['val' => 1, 'text' => 'Banana'],
        ['val' => 2, 'text' => 'Potato'],
        ['val' => 3, 'text' => 'Apple']
    ]
]);
```

Salida

```
<select id="products" name="products">
    <option value="1">Banana</option>
    <option value="2">Potato</option>
    <option value="3">Apple</option>
</select>
```
