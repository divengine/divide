# 2.11 Variables dinámicas dentro de un bucle

Las siguientes variables están disponibles en el ámbito del bucle.

|Variable|Tipo de dato|Descripción|
|---|---|---|
|$_item|mixed|Elemento actual|
|$_previous|mixed|El elemento anterior|
|$_next|mixed|El elemento siguiente|
|$_key|mixed|La clave del elemento en el array de PHP|
|$_index|integer|El índice del elemento (0..n-1)|
|$_index_random|integer|Índice aleatorio de la lista (0..n-1)|
|$_order|integer|El orden del elemento (1..n)|
|$_list|string|El nombre de la lista|
|$_is_last|boolean|Verdadero si el elemento actual es el último|
|$_is_first|boolean|Verdadero si el elemento actual es el primero|
|$_is_odd|boolean|Verdadero si el índice actual es impar|
|$_is_even|boolean|Verdadero si el índice actual es par|
