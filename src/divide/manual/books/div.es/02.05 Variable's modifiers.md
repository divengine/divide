# 2.5 Modificadores de variables

Los modificadores transforman una variable u obtienen información a partir de su valor. El modificador se coloca entre la llave de apertura y el nombre de la variable.

**Sintaxis**

|Modificador|Descripción|
|---|---|
|{$variable}|Sin transformación|
|{^variable}|Primer carácter en mayúscula|
|{^^variable}|Primer carácter de cada palabra en mayúscula|
|{^^^variable}|Mayúsculas|
|{_variable}|Minúsculas|
|{%variable}|Número de caracteres|
|{%%variable}|Número de palabras|
|{%%%variable}|Número de oraciones|
|{%%%%variable}|Número de párrafos|
|{&variable}|Codificación URL (ver `urlencode`)|
|{&&variable}|Codificación URL en bruto (ver `rawurlencode`)|
|{html:variable}|Entidades HTML (ver `htmlentities`)|
|{br:variable}|Convertir los saltos de línea en `<br>` (ver `nl2br`)|
|{json:variable}|Codificación JSON|
|{[mod]variable:~truncate-length}|Truncar; si existe `<!--break-->`, truncar ahí|
|{[mod]variable:/wordwrap-length}|Ajuste de línea por palabras|
|{[mod]variable:from,length}|Subcadena|
|{'variable}|Escapar las comillas simples no escapadas|
|{js:variable}|Escapar cadenas de JavaScript|
|{$variable:[format]}|Formato con `sprintf`|

**Ejemplo**

index.tpl

```html
{= title: mozilla firefox =}
{= body: A wonderful web browser =}

Nothing to change:
{$title}

Capitalize the first character:
{^title}

Capitalize each word:
{^^title}

Uppercase:
{^^^title}

Lowercase:
{_title}

Character count:
{%title}

Substring:
{$body:0,11}

Truncate:
{$body:~25}...

Word wrap:
{$body:/30}

Combined modifiers:
{^^^body:0,11}
{^^^body:/40}

String format:
{= value: 10 =}
{$value:%1$04d}
```

Salida

```html
Nothing to change:
mozilla firefox

Capitalize the first character:
Mozilla firefox

Capitalize each word:
Mozilla Firefox

Uppercase:
MOZILLA FIREFOX

Lowercase:
mozilla firefox

Character count:
15

Substring:
web browser

Truncate:
A wonderful...

Word wrap:
A wonderful web browser

Combined modifiers:
A WONDERFUL WEB BROWSER

A WONDERFUL

String format:
0010
```
