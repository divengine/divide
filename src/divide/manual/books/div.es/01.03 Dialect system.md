# 1.3 Sistema de dialectos

Div admite varios dialectos de plantillas.

Un dialecto se define externamente como un archivo JSON. Describe cómo una sintaxis de plantilla alternativa se corresponde con la sintaxis interna canónica de Div. Los dialectos no cambian el motor ni su comportamiento; solo afectan a cómo se interpreta la sintaxis de la plantilla.

Las plantillas pueden indicar en qué dialecto están escritas mediante una etiqueta dedicada. Esto permite que distintas plantillas, o fragmentos incluidos, usen dialectos diferentes dentro de la misma ejecución.

La traducción del dialecto ocurre antes del análisis, de modo que el analizador interno se mantiene consistente sea cual sea la sintaxis usada en las plantillas de origen. Esto permite:

- evitar colisiones de sintaxis con el lenguaje o formato que se genera,
- preservar restricciones de validez (como plantillas XML válidas),
- y trabajar con varias convenciones sintácticas en un único pipeline de generación.
