# 2.23 Compactar o limpiar el código resultante

Los bloques strip normalizan los espacios en blanco de la salida eliminando los espacios y saltos de línea redundantes.

**Sintaxis**

```
{strip}
    ... some code here ...
{/strip}
```

**Ejemplo**

index.tpl

```
{strip}
Hello Jack, ...

          ...the previous lines are of more.
{/strip}
```

Salida

```
Hello Jack, ...
...the previous lines are of more.
```
