# 2.6 Múltiples modificadores de variables

Se pueden encadenar varios modificadores usando la barra vertical como separador.

**Sintaxis**

```
{$varname|modifier1|modifier2|modifier3|...|}
```

**Ejemplo**

index.tpl

```
{= word: "ABCDEFG" =}

{$word|0,3|}
{$word|0,3|_|}
{$word|0,3|_|^|}
{$word|0,3|_|^|~2|}
```

**Salida**

```
ABC
abc
Abc
Ab
```
