# 2.34 Documentación de la plantilla

Div puede extraer metadatos de documentación incrustados en los comentarios de la plantilla. Cada propiedad de documentación empieza por `@` y el analizador la guarda. No hay una lista fija de propiedades; puedes definir las tuyas, pero Div ofrece una plantilla predeterminada que espera los campos habituales.

## 6.34.1 Propiedades estándar

|Variable/propiedad|Descripción|
|---|---|
|title|Título de la documentación. Puede pasarse mediante `$items` a `getDocsReadable`.|
|name|Nombre de la plantilla|
|description|Descripción de una sola línea|
|version|Versión de la plantilla|
|author|Autor|
|update|Fecha de la última actualización|
|vars|Lista de variables de la plantilla con el formato: obligatoria/opcional, tipo, nombre, descripción|
|include|Lista de plantillas incluidas (se añade automáticamente, pero puede sobrescribirse)|
|example|Fragmento de ejemplo de uso|

## 6.34.2 Sintaxis

```html
<!--{
    @first_property value
    @other_property value
    @multiline_property: line1
                         line2
                         line3
}-->
```

## 6.34.3 Ejemplo

index.tpl

```html
<!--{
    @name My template
    @description My first template with documentation
    @author Me
    @vars: required string title
           optional string body

    @example:
    {= title: "My first blog" =}
    {= body: "This is my first blog" =}
    {% blog.tpl %}
}-->
```

index.php

```php
<?php

include 'div.php';

div::docsOn();

$tpl = new div('index.tpl');
$tpl->parse();

echo $tpl->getDocsReadable();
```
