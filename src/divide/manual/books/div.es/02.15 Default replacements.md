# 2.15 Reemplazos por defecto

Los reemplazos por defecto asocian valores de entrada concretos con valores de salida alternativos.

## 6.15.1 Uso en PHP

```php
<?php

div::setDefault($value_to_search, $replace_with);
```

## 6.15.2 Uso en la plantilla

```
{@ [value_to_search, replace_with] @}
```

## 6.15.3 Ejemplo

index.php

```php
<?php

div::setDefault(true, "YES");

echo new div("index.tpl", [
    "haveproducts" => true,
    "havemoney" => false
]);
```

index.tpl

```
{@ [false, "NO"] @}

Have products: {$haveproducts}
Have money: {$havemoney}
```

Salida

```
Have products: YES
Have money: NO
```
