# 1.2 Comportamiento del motor

Div no procesa las plantillas en una única pasada de arriba abajo.

En su lugar, el motor analiza y transforma repetidamente toda la plantilla hasta que no se puedan hacer más cambios. Cada ciclo aplica las reglas de análisis (includes, condiciones, bucles, reemplazos, modificadores y bloques relacionados) al estado actual de la plantilla.

El proceso se detiene cuando se alcanza un resultado estable (un punto fijo) o cuando se llega a un límite de seguridad.

Pseudocódigo (conceptual):

```text
template = original
do:
    previous = template
    template = parse_pass(template, data)
while template != previous and cycles < MAX
```

Este comportamiento iterativo permite que las plantillas generen estructuras intermedias que se evalúan en ciclos posteriores. Como resultado, Div admite meta-plantillas y plantillas que generan otras plantillas sin depender de llamadas recursivas ni de un estado de ejecución oculto.
