# 2.35 Incluir otras plantillas

Las plantillas pueden dividirse en partes e incluirse desde una plantilla contenedora.

**Sintaxis**

```
{% var with path to the template part %}

or

{% path/to/template/part %}
```

**Ejemplo**

part.tpl

```
Hello world!
```

index.tpl

```
This is the container template:

{% part %}
```

Salida

```
This is the container template:

Hello world!
```

Nota: una plantilla no puede incluirse a sí misma.
