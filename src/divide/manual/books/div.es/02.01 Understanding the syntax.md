# 2.1 Entender la sintaxis

Div reconoce un pequeño conjunto de estructuras de bloque. La clasificación se basa en cómo se forman las etiquetas de apertura y cierre y en si los espacios en blanco son significativos.

## 6.1.1 Bloques rígidos

|Prefijo|Sintaxis rígida|Sufijo|
|---|---|---|
|PREFIJO|SINTAXIS RÍGIDA|SUFIJO|

Los bloques rígidos tratan cada carácter como significativo. Los espacios, tabuladores y saltos de línea forman parte de la sintaxis y no pueden insertarse para dar formato. Por ejemplo, en `{$text }` el nombre de la variable incluye el espacio final, así que el motor busca `text ` en lugar de `text`.

Bloques rígidos típicos: [[02.03 Reemplazos simples|02.03 Simple replacements]], [[02.35 Incluir otras plantillas|02.35 Including another templates]].

## 6.1.2 Bloques simples

|Inicio|Sintaxis flexible|Fin|
|---|---|---|
|INICIO|SINTAXIS FLEXIBLE|FIN|

Los bloques simples permiten espacios en blanco adicionales para mejorar la legibilidad. Las etiquetas de apertura y cierre son obligatorias, pero el contenido dentro de las etiquetas se analiza con reglas de espaciado flexibles.

Bloques simples típicos: [[02.22 Partes ignoradas (escapar del análisis de Div)|02.22 Ignored parts (escaping Div parsing)]], [[02.21 Comentarios|02.21 Comments]], [[02.23 Compactar o limpiar el código resultante|02.23 Strip or clean the resulting code]].

## 6.1.3 Bloques sin palabra clave

|Prefijo de inicio|Sintaxis flexible|Sufijo de inicio|
|---|---|---|
|PREFIJO_INICIO|SINTAXIS FLEXIBLE|SUFIJO_INICIO|
|CUALQUIER CÓDIGO + ETIQUETAS ESPECIALES|||
|FIN|||

Los bloques sin palabra clave codifican la etiqueta de apertura mediante un prefijo y un sufijo, mientras que la etiqueta de cierre no repite la palabra clave. Esta forma se usa cuando la etiqueta de cierre no es ambigua.

Bloques sin palabra clave típicos: [[02.14 Condiciones|02.14 Conditions]], [[02.12 Iteraciones|02.12 Iterations]].

## 6.1.4 Bloques con palabra clave

|Prefijo de inicio|Palabra clave|Sufijo de inicio|
|---|---|---|
|PREFIJO_INICIO|PALABRA_CLAVE|SUFIJO_INICIO|
|CUALQUIER CÓDIGO + ETIQUETAS ESPECIALES|||
|PREFIJO_FIN|PALABRA_CLAVE|SUFIJO_FIN|

Los bloques con palabra clave repiten la palabra clave tanto en la etiqueta de apertura como en la de cierre. Esta forma se usa cuando el bloque está anclado a una variable o un identificador concreto.

Bloques con palabra clave típicos: [[02.13 Partes condicionales|02.13 Conditional parts]], [[02.10 Listas (bucles)|02.10 Lists (loops)]].
