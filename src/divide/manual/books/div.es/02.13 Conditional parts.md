# 2.13 Partes condicionales

Las partes condicionales muestran u ocultan fragmentos de la plantilla según una variable booleana. El booleano se evalúa con `div::mixedBool`.

Reglas que usa `div::mixedBool`:

1. Falso si el valor es `false`.
2. Falso si el valor es `null`.
3. Falso si el valor numérico no es mayor que cero.
4. Falso si el valor es "0".
5. Falso si el valor es una cadena vacía.
6. Falso si el valor es un objeto sin propiedades.
7. Verdadero en cualquier otro caso.

Nota: el primer y el último espacio en blanco dentro de los bloques condicionales se recortan durante el análisis.

**Sintaxis**

```
?$var
    ... some code here ...
@else@
    ... some another code here ...
$var?

!$var
    ... some code here ...
@else@
    ... some another code here ...
$var!
```

**Ejemplo**

index.php

```php
echo new div('index.tpl', [
    'products' => [
        ['name' => 'Banana', 'price' => 20.5],
        ['name' => 'Potato', 'price' => 10.8]
    ]
]);
```

index.tpl

```
Products:

?$products
    [$products]
        {$name} - {$price}
    [/$products]
@else@
    No products
$products?

Similar result:

!$products
    No products
@else@
    [$products]
        {$name} - {$price}
    [/$products]
$products!
```

Salida

```
Products:

Banana - 20.5
Potato - 10.8

Similar result:

Banana - 20.5
Potato - 10.8
```
