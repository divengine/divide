# 2.39 Traductor de dialectos

Div puede traducir de cualquier dialecto al dialecto actual. La traducción usa las variables actuales de la plantilla como contexto, así que debes crear una instancia de div antes de traducir.

**Ejemplo**

index.php

```php
<?php

include 'div.php';

$tpl = new div('index.tpl');

$tpl->translateFrom([
    'DIV_TAG_IGNORE_BEGIN' => '{literal}',
    'DIV_TAG_IGNORE_END' => '{/literal}'
]);

$tpl->show();
```

index.tpl

```
{= name: "Peter" =}

{literal}
    {$name}
{/literal}

{$name}
```

index.tpl (traducido)

```
{= name: "Peter" =}

{ignore}
    {$name}
{/ignore}

{$name}
```
