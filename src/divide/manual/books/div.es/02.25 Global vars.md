# 2.25 Variables globales

Las variables globales persisten entre instancias de div.

**Sintaxis**

```php
<?php

div::setGlobal('var-name', $mixed_value);
```

**Ejemplo**

index.php

```php
<?php

div::setGlobal('today', date('Y-m-d'));

echo new div('index.tpl', [
    'name' => 'Peter'
]);

echo new div('index.tpl', [
    'name' => 'Jack'
]);
```

index.tpl

```
Hello {$name}
Today is: {$today}
```

Salida

```
Hello Peter
Today is 2012-08-17

Hello Jack
Today is 2012-08-17
```
