# 2.2 Variables (información, contenido...)

Las plantillas operan sobre "información" en lugar de sobre tipos de datos estrictos. Los arrays y los objetos se normalizan para que se pueda acceder a ambos de manera uniforme. A los valores anidados se accede con el operador punto.

Ejemplo:

**index.php**

```php
<?php

echo new div('index.tpl', [
    'single' => 'something',
    'complex' => [
        'single' => 45,
        'subcomplex' => [
            'single' => 60
        ]
    ]
]);

$complex = (object) [
    'single' => 45,
    'subcomplex' => ['single' => 60]
];

echo new div('index.tpl', [
    'single' => 'something',
    'complex' => $complex
]);
```

**index.tpl**

```php
Single value: {$single}
Single value into complex var: {$complex.single}
And more: {$complex.subcomplex.single}
```

**Salida**

```php
Single value: something
Single value into complex var: 45
And more: 60
```
