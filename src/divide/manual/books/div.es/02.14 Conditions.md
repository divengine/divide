# 2.14 Condiciones

Las condiciones evalúan una expresión booleana completa en lugar de una sola variable booleana. La expresión se interpreta como PHP después de la sustitución de la plantilla, así que la expresión resultante debe ser PHP válido.

**Sintaxis**

```
{?( ... expression ... )?}
    ... some code here ...
@else@
    ... some another code here ...
{/?}
```

**Ejemplo**

index.php

```php
echo new div('index.tpl', [
    'products' => [
        ['name' => 'Banana', 'price' => 20.5],
        ['name' => 'Potato', 'price' => 10.8]
    ]
]);
```

index.tpl

```
{?( {$products} > 0 )?}
    There are {$products} products in the warehouse
@else@
    There are not products in the warehouse
{/?}
```

Salida

```
There are 2 products in the warehouse
```

**Regla de las comillas**

Si una variable se compara como cadena, encierra el reemplazo entre comillas para que la expresión final sea PHP válido.

Correcto:

```
{?( "{$userRole}" === "guest" )?}
    {% loginPage %}
@else@
    {% dashboard %}
{/?}
```

Después de la sustitución:

```
"guest" === "guest"
```

Incorrecto (valor sin comillas):

```
{$userRole} === "guest"
```

Después de la sustitución:

```
guest === "guest"
```
