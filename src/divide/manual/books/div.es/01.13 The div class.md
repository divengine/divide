# 1.13 La clase div

Todas las funcionalidades del motor se proporcionan a través de la clase div. Si tu proyecto ya define una clase llamada div, puedes renombrar la clase Div o usar un alias de espacio de nombres.

## 4.1 Configuración y espacio de nombres

```php
<?php

include "div.php";

// Or using Composer
include "path/to/vendor/autoload.php";

// div class is inside the "divengine" namespace
use divengine\div;
```

## 4.2 Variantes de uso

1. Plantilla en línea

```php
echo new div('Hello {$name}', [
    'name' => 'Peter'
]);
```

2. Instanciar primero, renderizar después

```php
$t = new div('Hello {$name}', ['name' => 'Peter']);

echo $t; /* or $t->show(); */
```

3. Plantilla desde un archivo externo

```php
/* The file index.tpl contains the template code */

echo new div('index.tpl', ['name' => 'Peter']);
```

4. Datos proporcionados como cadena JSON

```php
echo new div('Hello {$name}', '{name: "Peter"}');
```

5. Datos cargados desde un archivo JSON

```php
/* The file index.json contains the data as JSON */

echo new div('index.tpl', 'index.json');
```
