# 2.7 Disección de cadenas

Los valores escalares pueden tratarse como cadenas y accederse como secuencias de caracteres. Puedes acceder a caracteres individuales con la notación de punto y recorrerlos como si fueran una lista.

Ejemplo

```
{= name: "Peter" =}

{$name.0}
{$name.1}

{= x: 537 =}

{$x.0}
{$x.1}

[$name]{$value} [/$name]

[$x] {$value} * [/$x] = (# [$x] {$value} * [/$x] 1 #)
```

Salida

```
P

e

5

3

P e t e r

5 * 3 * 7 = 105
```
