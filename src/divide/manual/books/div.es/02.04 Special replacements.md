# 2.4 Reemplazos especiales

Los reemplazos especiales emiten caracteres de control que de otro modo son difíciles de escribir en las plantillas.

|Etiqueta|Reemplazo|
|---|---|
|{\n}|\n|
|{\r}|\r|
|{\t}|\t|
|{\v}|\v|
|{\f}|\f|
|{\$}|$|

**Ejemplo**

index.tpl

```html
Hello{\n}Peter
{\t}Today is {/div.now:Y-m-d/}
```

Salida

```html
Hello
Peter
        Today is 2013-07-24
```
