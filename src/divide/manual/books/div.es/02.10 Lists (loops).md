# 2.10 Listas (bucles)

Las listas repiten un bloque de código de la plantilla por cada elemento de una colección.

**Sintaxis**

```
[$listvar]
    ... some code here ...
@empty@
    ... some code when the list is empty ...
[/$listvar]
```

## 6.10.1 Romper un bucle

Puedes detener la iteración con `@break@`. Todo lo que hay después de la etiqueta break en el cuerpo del bucle se ignora y el bucle se detiene.

Ejemplo

```
[$products]
    {?( {$_index} == 3 )?} <hr> @break@ {/?}
    {$value}<br>
[/$products]
```

**Ejemplo**

```php
echo new div('index.tpl', [
    'employees' => ['Rafa', 'Peter', 'John'],
    'products' => []
]);
```

**index.tpl**

```
Employees:

[$employees]
    {$value}
[/$employees]

Products:

[$products]
    {$name}
@empty@
    Empty list of products!
[/$products]
```

**Salida**

```
Employees:

Rafa
Peter
John

Products:

Empty list of products!
```
