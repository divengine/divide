# 4.3 Herencia de plantillas

Div no implementa una herencia explícita, pero se puede lograr un comportamiento equivalente con las funcionalidades existentes. Esta sección describe tres variantes.

## 8.3.1 Variante 1: includes alternativos

Usa una variable para elegir qué plantilla incluir.

```
{% block %}

// or

{% {$block} %}
```

## 8.3.2 Variante 2: variables de plantilla protegidas

La plantilla padre define una variable protegida para un bloque. La plantilla hija la redefine e incluye a la padre.

parent.tpl

```
... any code ...
{= block1:

... code of block 1 ...

=}

... another code...

{$block1}
```

child.tpl

```
{= *block1:

    ... another code for block 1 ...

=}

{% parent %}
```

## 8.3.3 Variante 3: ubicaciones

Define ubicaciones en la padre y rellénalas desde la hija.

parent.tpl

```
... any code ...

(( block1 ))

... another code...

{= parent_block1:

... code block 1 written by the parent ...

=}
```

child.tpl

```
{% parent %}

{{block1
    {$parent_block1}

... The child's content ...

block1}}
```

Salida

```
... any code ...

... code block 1 written by the parent ...
... The child's content ...

... another code...
```
