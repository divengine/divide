# 2.3 Reemplazos simples

Un reemplazo simple sustituye una variable por su valor. El reemplazo depende del tipo del valor:

1. Cadena: el contenido de la cadena.
2. Número: el valor numérico.
3. Array: la longitud del array.
4. Objeto sin `__toString`: el número de propiedades del objeto.

**Sintaxis**

```
{$varname}
```

**Ejemplo**

**index.php**

```php
<?php

include 'div.php';

echo new div('index.tpl', [
    'first_name' => 'Peter',
    'last_name' => 'Pan'
]);
```

**index.tpl**

```
First name: {$first_name}
Last name: {$last_name}
```

**Salida**

```
First name: Peter
Last name: Pan
```
