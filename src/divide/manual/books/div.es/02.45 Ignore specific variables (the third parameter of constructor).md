# 2.45 Ignorar variables específicas (el tercer parámetro del constructor)

Puedes indicarle al motor que ignore ciertas variables pasando una lista de nombres como tercer parámetro del constructor.

```php
/* Third parameter as array */

echo new div('index.tpl', ['name' => 'Peter'], ['name']);

/* Third parameter as string */

echo new div('index.tpl', ['name' => 'Peter', 'age' => 25, 'sex' => 'M'], 'name,age');
```
