# 2.18 Cápsulas

Una cápsula aísla una parte de una plantilla y vuelve a asociar el ámbito de los datos a una sola variable. Esto reduce la repetición y mejora la legibilidad.

**Sintaxis**

```
[[varname
    ... code using properties of varname ...
varname]]
```

**Ejemplo**

index.php

```php
<?php

echo new div('index.tpl', [
    'product' => [
        'name' => 'Banana',
        'price' => 20.5,
        'tax' => 1.5
    ]
]);
```

index.tpl

```
Product:

[[product
    Name: {$name}
    Price: {$price}
    Tax: {$tax}
product]]

Similar:

    Name: {$product.name}
    Price: {$product.price}
    Tax: {$product.tax}
```

Salida

```
Product:

    Name: Banana
    Price: 20.5
    Tax: 1.5

Similar:

    Name: Banana
    Price: 20.5
    Tax: 1.5
```
