# 2.43 Hooks

Los hooks son métodos que puedes implementar en una clase que extiende div. Se invocan en puntos concretos del ciclo de vida.

Hooks disponibles:

- `beforeBuild`
- `afterBuild`
- `beforeParse`
- `afterParse`

El hook `beforeBuild` puede modificar `$src` y `$items` antes de que empiece el análisis.

**Ejemplo**

index.php

```php
class Page extends div{
    public function beforeBuild(&$src = null, &$items = null){
        $this->title = 'Hello World';
        $items['body'] = 'This is the hook!';
    }
}

echo new Page('index.tpl');
```

index.tpl

```
<h1>{$title}</h1>
<p>{$body}</p>
```

Salida

```
<h1>Hello World</h1>
<p>This is the hook!</p>
```
