# Help

This manual is inside divide too. **F1** opens it at the topic of the window you are in, in a help window coloured like the one in Borland Pascal: black on cyan, cross references in yellow.

![the help window on the Dialector topic](images/help.png)

## Opening the help

| Key | Menu | |
|---|---|---|
| **F1** | Help > Using help | the topic of the active window: the editor, a data file, the project, the dialector, the output, the messages |
| | Help > Contents | the table of contents |
| **Shift+F1** | Help > Index | every topic and every section, alphabetically |
| **Ctrl+F1** | Help > Topic search | the topic of the word under the editor's cursor (for example *dialect*, *completion*, *render*); the index when no topic matches |
| **Alt+F1** | Help > Previous topic | back to the topic you came from |

F1 in the help window itself shows this page.

![the index: every topic and section, alphabetically](images/help-index.png)

## Moving in the help window

| Key | |
|---|---|
| **Tab** / **Shift+Tab** | next / previous cross reference |
| **Enter** or a click | follow the cross reference |
| **Alt+F1** / **Backspace** | previous topic |
| **↑ ↓ PgUp PgDn Home End** | scroll |
| **Esc** | close the help window |

The help window is a window like the others: **F5** zooms it, **F6** moves to the next window and back, and the help stays where you left it.

## What the help contains

The same pages as the [divide wiki](https://github.com/divengine/divide/wiki), without the screenshots. Links to other topics are cross references; links to web sites are underlined and open nothing.
